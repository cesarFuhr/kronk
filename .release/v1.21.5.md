# Release Notes - 1.21.5

**Release Date:** March 23, 2026

## Overview

Version 1.21.5 is a maintenance and infrastructure release focused on improving the Nix build system, streamlining version management, updating the default server port, and refining documentation and benchmarks.

---

## Breaking Changes

### Port Change to 11435 (#430)
- The default Kronk server port has changed from its previous value to **11435**
- All documentation, agent configs, Docker Compose files, and BUI components have been updated accordingly
- Update any custom configurations, scripts, or client integrations that hardcode the old port

---

## Improvements

### Nix Build System Overhaul
- Migrated from the previous Nix build approach to `buildGoApplication` using **gomod2nix** for more reliable and reproducible Go builds
- Added `gomod2nix.toml` lockfile tracking all Go module dependencies for Nix
- Added a pre-commit hook to keep `gomod2nix.toml` in sync
- Removed the now-unnecessary `nix-update` GitHub Actions workflow
- `flake.nix` is no longer part of the release cycle (excluded from goreleaser)
- Fixed dependency SHAs in the Nix flake

### Version Management Simplification
- Consolidated version source of truth into `sdk/kronk/kronk.go` (removed the `VERSION` file)
- Removed `ldflags` version injection from goreleaser — version is now a plain constant
- Updated the makefile to derive version info directly from `kronk.go`

### Downloaded Binaries in Nix (#426)
- The Nix flake now uses Kronk's own downloaded llama libraries instead of Nix-packaged ones
- Significantly simplified `flake.nix` (86 lines reduced to ~30)
- Build scripts updated to use the downloaded library versions

## Upgrade Notes

### Port Migration
If you have any of the following, update the port from the old value to `11435`:
- Docker Compose files
- Client integrations (OpenAI-compatible clients, etc.)
- Agent config files (Cline, Kilo/OpenCode, etc.)
- Custom scripts or systemd services

### Nix Users
Run `gomod2nix` after any `go.mod` changes to keep `gomod2nix.toml` up to date. The pre-commit hook will enforce this going forward.
